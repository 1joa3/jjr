# JJR Contabilidade Estratégica

Plataforma SPA (Single Page Application) de alta conversão, desenhada para projetar autoridade e facilitar a jornada do cliente.

## Estrutura Funcional
- **Navbar & Hero:** Navegação intuitiva e proposta de valor focada em crescimento e segurança fiscal.
- **Serviços (Grid):** Cards explicativos para Abertura, Contabilidade Mensal, Transição de MEI e IR.
- **Autoridade:** Painel de métricas (+10 anos, +1.5k clientes) e diferenciais (Praticidade, Segurança).
- **Humanização:** Seção "Conexão" para estreitar laços entre equipe e cliente.
- **Lead Gen:** Formulário de contato inteligente com segmentação por tipo de negócio.

## Diferenciais Tecnológicos
- **IA Assistant:** Chatbot integrado com **Gemini API** (modelo `gemini-3-flash-preview`) para suporte fiscal 24/7.
- **UI/UX:** Design mobile-first com Tailwind CSS, ícones Lucide e tipografia equilibrada (Inter/Playfair Display).
- **Performance:** Componentização otimizada em React 19 para carregamento instantâneo.

Objetivo: Simplicidade técnica com máximo impacto comercial.
